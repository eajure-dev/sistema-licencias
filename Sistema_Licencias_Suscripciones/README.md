# Sistema de Licencias - Administración de Planes

Esta versión permite administrar los planes desde el panel web:
- Crear planes
- Editar nombre, precio, duración, equipos, actualizaciones y beneficios
- Activar o desactivar planes
- Eliminar planes que no tengan licencias asociadas

Si un plan ya tiene clientes/licencias asociadas, el sistema bloquea su eliminación para no romper el historial.
